# Modding

Shadow Crystal Engine is designed with modding in mind.

The engine provides support for creating custom songs, charts, characters, stages, events, gameplay mechanics, and other custom content.

Shadow Crystal Engine also aims to provide compatibility with existing Friday Night Funkin' modding systems, including Psych Engine and its Lua scripting system.

## Psych Engine Compatibility

Shadow Crystal Engine will include support for importing and running content from Psych Engine.

The goal is to provide compatibility with Psych Engine mods while requiring as few changes as possible.

This includes support for:

- Psych Engine mod structures
- Psych Engine Lua scripts
- Psych Engine events
- Psych Engine characters
- Psych Engine stages
- Psych Engine charts
- Other compatible mod content

Compatibility is still being developed, and some features may require changes depending on the Psych Engine version and the features used by a specific mod.

Shadow Crystal Engine does not aim to compete with Psych Engine or replace it.

Psych Engine and other compatible engines have their own features, workflows, and communities. Shadow Crystal Engine simply aims to provide an alternative experience while maintaining compatibility with existing content where possible.

## Lua

Shadow Crystal Engine includes Lua scripting support for mods.

Lua can be used to customize gameplay and add functionality without directly modifying the engine source code.

The Lua system is also being developed with Psych Engine compatibility in mind, allowing existing Psych Engine Lua scripts to be used with as few modifications as possible.

# Purpose

Shadow Crystal Engine is not designed specifically for professional mod development or large-scale commercial projects.

The engine was created with practicality, accessibility, and fun in mind.

Its purpose is to provide players and creators with a simple and enjoyable way to experiment with Friday Night Funkin', create custom content, and play different types of projects without requiring an overly complicated development setup.

Shadow Crystal Engine is also not intended to replace other Friday Night Funkin' engines.

Compatibility with other engines and their modding systems is intended to make it easier for existing content to work with Shadow Crystal Engine, not to replace the engines it is compatible with.

If a project is better suited for another engine, there is no reason to move it to Shadow Crystal Engine.

Shadow Crystal Engine is simply another option for people who want to create, experiment, or have fun with Friday Night Funkin'.

# Shadow Crystal Engine

Shadow Crystal Engine is an independent fan-made engine based on Friday Night Funkin'.

The engine is primarily focused on practicality, accessibility, experimentation, and having fun rather than being a professional development solution.

It is not intended to replace Psych Engine or any other compatible Friday Night Funkin' engine. Compatibility features exist to make it easier for players and creators to use existing content, not to compete with or replace the original engines.

Shadow Crystal Engine is not affiliated with or officially endorsed by the Friday Night Funkin' or Psych Engine development teams.

More information about Shadow Crystal Engine and its development can be found throughout this repository.
