# Integración de los perfiles Freeplay / Options

El ZIP incluye el editor y el guardado de perfiles. Para evitar reemplazar los estados completos del fork (y perder tus personalizaciones), la aplicación de los perfiles se deja como cambios localizados. Sigue la sección correspondiente de README.md sobre `FreeplayState.hx` y `OptionsState.hx`.

Perfiles guardados:
- `mods/<mod>/data/menu-layout-freeplay.json`
- `mods/<mod>/data/menu-layout-options.json`

Quick Panel: permanece exclusivamente en Main Menu.
